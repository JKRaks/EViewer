# 收藏与浏览历史

[返回首页](../../README.md) · [搜索与阅读](search-and-reading.md)

| 数据 | 保存位置 | 用途 |
| --- | --- | --- |
| 个人收藏 | 源站账号 | 按分类整理想保留的画册 |
| 浏览历史与阅读位置 | 当前浏览器的 IndexedDB | 找回读过的内容，继续上次阅读 |

## 添加与管理收藏

先在「账号信息」完成当前连接模式的登录验证，然后打开画册详情：

1. 点击「添加收藏」。
2. 选择收藏夹。
3. 点击「确认收藏」。

已收藏的画册会显示「管理收藏」。可以改选分类并点击「更新分类」，也可以「取消收藏」。修改会同步到源站账号。

在「个人收藏」页面，可以切换分类、搜索收藏，并按「更新时间」或「收藏时间」排序。点击刷新按钮可重新获取列表。

### 批量整理

展开「批量操作」，选择要处理的画册，再选择目标收藏分类并点击「移动」。删除收藏会要求确认；确认前核对已选数量。

删除收藏与删除浏览历史互不替代。取消收藏后，本地可能仍留有浏览记录；清理浏览历史也不会替你取消源站收藏。

### 收藏分类没有更新

先刷新「个人收藏」。如果分类仍与源站不一致，可以到「系统设置 → 缓存维护 → 用户配置缓存」点击「重建」。重建后会重新读取当前用户配置和收藏分类。

## 查看浏览历史

在「系统设置 → 缓存偏好」开启「开启 IndexedDB」和「记录浏览历史」。开启后，阅读器会记录已看图片和上次阅读位置；关闭记录后，历史入口会隐藏。

「浏览历史」列出画册、已看张数、上次位置和时间。点击记录进入画册详情。每条记录的更多操作里可以收藏或删除；触屏设备也可横向滑动记录，显示操作按钮。

历史列表按当前画廊站点筛选。切换 E-Hentai / ExHentai 后看到的记录不同，不一定是数据丢失。

## 清理记录

- 删除单条：在该记录的操作菜单中选择「删除」，确认后移除。
- 清空历史：点击「清空全部」。
- 系统设置清理：在「数据清理」中清除浏览历史，或完全清理 IndexedDB。

「清空全部」清理的是浏览器中全部浏览历史，不只是当前列表展示的站点。完全清理 IndexedDB 还会清除标签翻译、画册详情、图片信息及翻译收集记录。

浏览历史依赖浏览器存储。无痕模式、存储空间不足、站点数据清理都可能影响记录；当前没有阅读历史跨设备同步功能。需要长期保留的画册，建议加入源站收藏。
