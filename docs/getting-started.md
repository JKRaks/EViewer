# 首次使用

已有 EViewer 实例时，直接打开网站。还没有实例，可先按[部署指南](deployment.md)部署。下面的配置在 EViewer 页面中完成。

## 选择连接方式

打开「系统设置 → 浏览器助手」。

- **服务代理**：由已部署的 Worker 访问源站，适合不使用浏览器助手的环境。
- **本机代理（Beta）**：由助手使用当前浏览器的源站会话，需要脚本管理器、网站权限和可用的源站连接。

这里选择的方式同时用于画廊和 HentaiVerse。本机模式失败后不会自动回退到服务代理；切换方式后应重新检查登录状态。

同一区域可选择 E-Hentai 或 ExHentai。后者要求账号已有源站访问权限，EViewer 不会替账号取得权限。

## 使用浏览器助手

### 安装

1. 在「安装与更新」中选择脚本管理器。桌面 Chrome、Edge、Firefox 等使用 Tampermonkey；Safari 使用 Userscripts。Android 需要支持相应扩展的浏览器。
2. 按页面链接安装管理器。Userscripts 还需要在 App 中选择脚本目录，并在 Safari 设置中启用扩展。
3. 点击「安装浏览器助手」，在管理器页面确认安装与权限。
4. 只保留一份 EViewer 助手，停用旧版登录脚本或实验连接器。
5. 允许扩展访问 EViewer 及所选源站，刷新 EViewer，点击「重新检测」。

显示「浏览器助手已连接」后，即可选择「本机代理」。iPhone、iPad 和 Mac 的 Safari 助手请在普通标签页中使用。

### 检查登录

在同一浏览器登录所选源站，然后打开「账号信息 → 认证信息」，点击「检测源站登录」。本机模式直接使用源站会话，不向服务代理同步 Cookie。

若脚本版本与正式站点不同，按页面提示更新或重新安装，再刷新检测。开发、预览环境可能与 `main` 版本不同，先确认自己访问的是哪个环境。

## 使用服务代理

在「账号信息 → 认证信息」查看「登录态」。需要手动配置时，在「Cookie 手动维护」中选择输入 Cookie 字符串，或仅输入所需值。

认证所需字段为 `ipb_member_id` 和 `ipb_pass_hash`。使用 ExHentai 如需 `igneous`，可通过 Cookie 字符串一并导入。保存后打开账号总览，确认账号信息正常显示。

浏览器助手也承担源站登录授权相关功能。本机请求和向服务代理授权是不同操作，授权前应确认目标实例和页面提示。

Cookie 属于登录凭据。只在自己部署或信任的实例中填写，不要放进仓库、Issue、聊天截图或录屏。

## 开始阅读

打开首页或搜索页，选择画廊进入详情，再打开阅读器。第一次使用可以检查：

- 所选站点和连接方式是否正确。
- 画廊详情与图片是否能正常加载。
- 「系统设置」中的本地存储及阅读历史是否启用。

阅读历史存于当前浏览器，换设备或浏览器后不会自动同步；清理站点数据也会影响记录。完整操作见[搜索与阅读](guide/search-and-reading.md)和[收藏与历史](guide/favorites-and-history.md)。

遇到问题请看[常见问题](troubleshooting.md)。
