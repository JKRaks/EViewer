# 常见问题

## 没检测到浏览器助手

在普通浏览器标签页打开「系统设置 → 浏览器助手」，检查管理器已启用、脚本已安装，且获准访问 EViewer 与所选源站。刷新页面后点击「重新检测」。

如果检测到多个助手，只保留一份，停用旧登录脚本和实验连接器。版本不一致时从当前正式站点更新脚本，不要混用预览版。iOS/iPadOS 的主屏幕 PWA 与 Safari 普通标签页不是同一扩展环境。

没有弹出安装页时，可使用设置中提供的下载脚本或复制地址入口；Userscripts 文件应保存为 `.user.js`，不是网页或 `.txt`。

## 切换到本机代理后不能访问

先确认同一浏览器能打开所选源站，并已登录。然后在「账号信息 → 认证信息」点击「检测源站登录」。

本机请求失败不会自动切回服务代理。需要切换时，请在设置中主动选择并检查该模式的登录态，不要只反复刷新阅读页。

## 已保存 Cookie，但账号或 ExHentai 仍不可用

保存配置后，请通过账号总览检查登录状态。检查所选站点、当前连接方式、凭据是否仍有效，以及账号是否已有 ExHentai 权限。服务代理如需 `igneous`，通过 Cookie 字符串一并导入。

不要在 Issue 中附 Cookie 原文。反馈时只提供错误信息和操作步骤，并遮盖账号、Token 与认证字段。

## 图片加载失败或阅读位置没有恢复

单张图片失败可尝试阅读器中的重试。多张图片同时失败时，先检查连接与源站状态，不必立即清空所有缓存。

阅读历史依赖 IndexedDB 和对应开关。检查「系统设置」中的存储状态；无痕模式、浏览器存储限制或空间不足可能导致写入失败。历史按画廊站点区分，切换 E-Hentai / ExHentai 后列表可能不同。

换设备、换浏览器或清理站点数据不会自动带走原来的本地历史。清理历史前确认是否还需要保留阅读位置。

## 安装 PWA 后能否离线阅读

安装 PWA 后可从独立窗口打开 EViewer，部分应用资源会缓存在本地。阅读画廊和进行源站操作仍需联网。

## iPhone / iPad 的 PWA 下载按钮没有直接保存文件

当前下载页会尝试系统分享，失败时改为复制下载链接，提示在 Safari 中打开。可以在普通 Safari 标签页继续操作。取消分享后可以重新打开下载链接。

下载页的「源站下载」目前暂不支持；种子列表为空也不等于网页阅读不可用。

## HentaiVerse 角色维护页面暂时不能操作

源站可能在战斗期间锁定角色维护页面。检查是否仍在战斗，按界面提示恢复、完成或退出后重新加载。

## 本地开发打开了页面，但请求失败

`npm run dev` 只启动 Vite。检查代理是否在运行、`VITE_EH_URL` 是否正确，以及不同源情况下的白名单。`npm run preview` 也不是完整 Worker 服务。

完整入口先执行 `npm run build`，再运行 `npm run dev:worker`。配置见[本地开发](development.md)。

## 发布提示构建版本不一致

确认发布参数是当前 HEAD 的完整 40 位提交编号，工作树已提交，再重新构建。不要拿旧 `dist` 发布新提交。发布脚本会比较构建版本与目标提交，具体流程见[部署指南](deployment.md)。
