# 界面国际化

使用 Vue I18n Composition 模式，支持 `zh-CN` 和 `en` 两种语言。默认跟随浏览器语言，用户选择保存在 `eviewer-locale` 中；存储不可用时仍可切换。语言切换入口位于系统设置底部，切换时不会重新挂载页面或重置业务状态。

## 翻译机制

`en.json` 使用中文原文作为键值，便于审阅；中文词典由键自动生成。

- 静态文案：`t('搜索画册')`
- 动态句子：`t('第 {p0} 张', { p0: ordinal })`
- 日期和数字格式使用 `getDisplayLocale()`

**注意**：源站请求值、枚举、缓存键和判断条件不要调用 `t` 函数。

## 内容保留策略

- 画册标题、用户昵称、评论等内容保留原文
- 中文标签通过 Worker 翻译；英文模式显示原文，不改变标签身份或查询参数
- HentaiVerse 保持既有模型的规范文本和动作值，展示时使用维护的术语及解析时保留的英文原文
- 切换语言不会触发战斗动作
- 源站缺少原文的内容按既有逻辑回退

## 标签处理

画册标签统一由 `GalleryTagPopover` 展示和交互。搜索通过 `createGalleryTagSearchRoute` 使用原始命名空间和标签名生成查询条件，中文译名仅用于显示。切换语言后仍能跳转到相同的标签查询。

## 开发要求

新增界面文案时必须同步补充英文词典，保持插值参数一致。脚本生成的提示和无障碍标签也要使用当前语言。

HentaiVerse 的补充术语维护在 `src/core/hentaiverse/hentaiVerseInterface.en.json`。已知战斗日志在解析时会保留英文原文，未知源站内容保持原样。
