# 界面国际化

使用 Vue I18n Composition 模式，支持 `zh-CN` / `en`。默认跟随浏览器语言，用户选择保存在 `eviewer-locale`；存储不可用时仍可切换。入口位于系统设置底部，不重挂载页面或重置业务状态。

`en.json` 使用中文原文作为可审阅的键；中文词典由键生成。`t('搜索画册')` 翻译静态文案，动态句子使用 `t('第 {p0} 张', { p0: ordinal })`。日期和数字格式使用 `getDisplayLocale()`。源站请求值、枚举、缓存键和判断条件不得调用 `t`。

画册标题、用户昵称、评论等内容保留原文。中文标签通过原 Worker 翻译；英文模式显示 master/原名，不改标签身份或查询参数。HentaiVerse 保持既有模型的规范文本和动作值，展示时使用已维护的术语及解析时保留的英文原文；切语言不发起战斗动作。源站缺少原文的内容按既有回退呈现。

新增界面文案必须同步补充英文词典，插值参数保持一致；由脚本创建的提示和无障碍标签也使用当前语言。HentaiVerse 的补充术语维护在 `src/core/hentaiverse/hentaiVerseInterface.en.json`，已知战斗日志在解析时保留英文原文，未知源站内容保留原样。

画册标签统一由 `GalleryTagPopover` 展示和交互；搜索通过 `createGalleryTagSearchRoute` 使用原始命名空间和标签名生成条件，中文译名仅用于显示。切换语言后仍应跳转到同一个标签查询。
